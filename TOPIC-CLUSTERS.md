# Clústeres de Autoridad Temática (Topic Clusters) — Electro Flor Perú

Para construir **autoridad temática (Topical Authority)** en Google según el sistema Helpful Content, no basta con tener páginas de producto aisladas. Es indispensable estructurar núcleos temáticos completos (*Hub & Spoke*) donde guías informativas de alto valor canalicen autoridad hacia las categorías y fichas transaccionales de cotización.

```
                  [Página Pilar / Categoría Transaccional]
                       ▲                 ▲
                      /                   \
        [Artículo de Guía / Blog] ◄-----► [Herramienta / Ficha Técnica]
```

## Reglas de Enlazado Interno Obligatorias

1. **Bidireccionalidad Obligatoria**: Cada artículo de blog DEBE enlazar a su categoría transaccional correspondiente en el primer tercio del contenido.
2. **Anchor Text Específico**: Prohibido usar anchors genéricos como *"haz clic aquí"* o *"ver más"*. Usar siempre términos de la entidad (*"cables indeco libres de halógeno"*, *"campanas industriales high bay"*).
3. **Página de Producto a Calculadora y Ficha Técnica**: Cada producto relevante de cables debe incluir un enlace contextual hacia la calculadora de conductores.
